# 小院时光 · A Little Courtyard

一个纯前端的 3D 微缩小院（Three.js 单文件，无需构建）。点击房子可以走进屋内，用游戏方式逛三个房间；小女孩会在院子里散步、荡秋千、坐长椅、看鱼，也会回屋里走动。

## 运行

任选其一：

- 直接双击打开 `index.html`（需联网加载 Three.js CDN 与天气数据）
- 或本地起服务：`python -m http.server 8080` 后访问 `http://localhost:8080`

## 玩法与操作

**院子（外景）**

| 操作 | 效果 |
| --- | --- |
| 左键拖拽 / 滚轮 / 右键 | 环绕旋转 / 缩放 / 平移 |
| 点小女孩 | 原地挥手蹦跳（坐秋千、坐长椅时也会打断） |
| 点小猫 / 小兔子 | 小猫蹦跳摇尾巴、兔子原地欢跳 |
| 点房子 | 进入室内场景 |
| 底部面板 | 昼夜切换、自动旋转开关、城市切换 |

**室内（点击房子进入）**

| 操作 | 效果 |
| --- | --- |
| WASD / 方向键 | 在房间里走动（卧室 / 起居室 / 厨房） |
| 按住拖拽 | 环视四周 |
| ESC / 「回到院子」按钮 / 点屋内木门 | 回到院子 |

屋内的窗户与房子外墙的门窗一一对应，透过窗户能直接看到院子里真实的草坪、篱笆与绿树。小女孩进屋休息时，会自己走去书桌前、坐床沿、看书架、在厨房台前忙活。

屋里的光会跟着院子外的时间走：白天阳光斜穿窗洞，在地板上投出窗棂的影子；入夜后吊灯、落地灯、床头灯、厨房灯依次亮起，把三个房间照成一团团暖黄的光晕。窗户有窗台和玻璃，墙脚有踢脚线，两道隔墙的门洞加了过梁和门套，家具底下压着柔和的接地阴影。

## 特色细节

- **真实时区与天气**：选择城市后按当地时刻自动昼夜切换，并调用 Open-Meteo 实时天气，雨雪雾各有视觉效果（时钟栏显示天气文字）
- **雨天小剧场**：下雨时小女孩自动撑起小红伞；雨停后白天会出现彩虹
- **夜晚限定**：窗灯、串灯、灯笼点亮，萤火虫与流星
- **院子生态**：锦鲤巡游、鸭子排队游泳、青蛙鼓腮、蝴蝶蜜蜂小鸟、向日葵追日、炊烟、气球与悬浮小岛
- **女孩的日常**：随机散步、池塘边看鱼、坐长椅、荡秋千（和小熊并排）、回房休息，五种状态自动切换

## 调试彩蛋

URL 加参数可强制天气，方便演示：

- `?wx=clear|cloudy|rain|snow|fog` 固定某种天气
- `?wx=cycle` 每 18 秒轮播五种天气（雨停时还能看到彩虹）
- `?inside` 直接进屋，`?inside&cam=x,z,yaw` 还能指定室内相机落点

控制台调试钩子：`__yard()` 查看状态、`__yardStep(n)` 手动推帧、`__yardGoto('swing')` 等触发指定活动、`__yardEnv(1)` 直接跳到夜晚（0 是白天）、`__yardPerf()` 看当前的 draw call / 阴影投射体 / 几何体数量。

## 技术

Three.js r160（CDN import map）+ 原生 WebGL 渲染，单文件约 3300 行；所有模型由基础几何体程序化搭建，无外部素材。天气数据来自 [Open-Meteo](https://open-meteo.com/)（免费、无需密钥）。

场景由一千多个小零件堆成，瓶颈在 draw call 而不是三角形，所以做了几件事：同规格的盒/柱/球共用一份几何体（1465 → 781）；半径小于 0.16 的装饰件不投影，因为它们在阴影贴图里不足几个纹素（投影体 1426 → 638）；在院子里时屋内家具完全不投影，反正外壳挡着太阳；阴影贴图从 4096 收到 2048、相机范围从 ±21 收到 ±15，纹素密度反而更高；时区解析和时钟 DOM 写入按 0.5 秒节流，动画循环里不再有每帧的临时对象。另外加了自适应分辨率：持续掉帧就降采样，顺畅了再升回去。
