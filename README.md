# 小院时光 · A Little Courtyard

一个纯前端的 3D 微缩小院（Three.js 单文件，无需构建）。点击房子可以走进屋内，用游戏方式逛三个房间；小女孩会在院子里散步、荡秋千、坐长椅、看鱼，也会回屋里走动。

## 运行

任选其一：

- 直接双击打开 `index.html`（需联网：Three.js 从 jsDelivr CDN 加载，天气走 Open-Meteo）
- 或本地起服务：`python -m http.server 8080` 后访问 `http://localhost:8080`
- 可选发布：把仓库推到 GitHub 后在仓库 Settings → Pages 选分支即可（静态单页，无构建）

## 玩法与操作

**院子（外景）**

| 操作 | 效果 |
| --- | --- |
| 左键拖拽 / 滚轮 / 右键 | 环绕旋转 / 缩放 / 平移 |
| 点小女孩 | 原地挥手蹦跳（坐秋千、坐长椅时也会打断） |
| 点小猫 / 小兔子 | 小猫蹦跳摇尾巴、兔子原地欢跳 |
| 点房子 | 进入室内场景 |
| 底部面板 | 昼夜切换、画质、环境音开/关、自动旋转、城市、拍照 |

**室内（点击房子进入）**

| 操作 | 效果 |
| --- | --- |
| WASD / 方向键 | 在房间里走动（卧室 / 起居室 / 厨房） |
| 按住拖拽 | 环视四周 |
| ESC / 「回到院子」按钮 / 点屋内木门 | 回到院子 |

屋内的窗户与房子外墙的门窗一一对应，透过窗户能直接看到院子里真实的草坪、篱笆与绿树。小女孩进屋休息时，会自己走去书桌前、坐床沿、看书架、在厨房台前忙活。

## 特色细节

- **真实时区与天气**：选择城市后按当地时刻自动昼夜切换，并调用 Open-Meteo 实时天气，雨雪雾各有视觉效果（时钟栏显示天气文字）
- **雨天小剧场**：下雨时小女孩自动撑起小红伞；雨停后白天会出现彩虹
- **夜晚限定**：窗灯、串灯、灯笼点亮，萤火虫与流星
- **院子生态**：锦鲤巡游、鸭子排队游泳、青蛙鼓腮、蝴蝶蜜蜂小鸟、向日葵追日、炊烟、气球与悬浮小岛
- **女孩的日常**：随机散步、池塘边看鱼、坐长椅、荡秋千（和小熊并排）、回房休息，五种状态自动切换
- **可选环境音**：面板「环境音 开/关」，默认静音；Web Audio 程序化软风 / 雨声 / 夜虫（无外部音频文件）

## 调试彩蛋

URL 加参数可强制天气，方便演示：

- `?wx=clear|cloudy|rain|snow|fog` 固定某种天气
- `?wx=cycle` 每 18 秒轮播五种天气（雨停时还能看到彩虹）

控制台调试钩子：`__yard()` 查看状态、`__yardStep(n)` 手动推帧、`__yardGoto('swing')` 等触发指定活动。

## 技术

Three.js r160（jsDelivr CDN import map；需联网）+ 原生 WebGL 渲染，单文件、无构建；模型与可选环境音均为程序化生成，无外部贴图或音频素材。天气数据来自 [Open-Meteo](https://open-meteo.com/)（免费、无需密钥）。
