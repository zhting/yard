# 小院时光 · A Little Courtyard

一个纯前端的 3D 微缩小院（Three.js 单文件，无需构建）。点击房子可以走进屋内，用游戏方式逛三个房间；小女孩会在院子里散步、荡秋千、坐长椅、看鱼，也会回屋里走动。

## 运行

推荐用一键启动脚本（会本地起服务，并用显卡加速打开 Chrome / Edge）：

- **Windows**：双击 `start.bat`
- **macOS / Linux**：终端里运行 `./start.sh`

也可以手动：`python -m http.server 8080` 后访问 `http://localhost:8080`。
直接双击 `index.html` 也能打开，但浏览器不让页面读取本地的人物模型文件，会改从 GitHub 下载（约 10MB）。
需联网：Three.js / three-vrm 从 jsDelivr CDN 加载，天气走 Open-Meteo。

### 显卡加速

页面跑在浏览器的 WebGL 上，本身就是用本机 GPU 渲染的：

- 渲染器以 `powerPreference: 'high-performance'` 创建，双显卡笔记本会优先用独立显卡
- 启动脚本额外加了 `--ignore-gpu-blocklist --enable-gpu-rasterization --force_high_performance_gpu`，显卡被浏览器拉黑时也强制启用
- 如果检测到浏览器在用 CPU 软件渲染（SwiftShader / llvmpipe 等），会自动降到「画质 低」并提示去浏览器设置里打开「硬件加速」
- 控制台会打印实际使用的 GPU 型号；`__yardGPU()` 也能查看
- 可选发布：把仓库推到 GitHub 后在仓库 Settings → Pages 选分支即可（静态单页，无构建）

## 玩法与操作

**院子（外景）**

| 操作 | 效果 |
| --- | --- |
| 左键拖拽 / 滚轮 / 右键 | 环绕旋转 / 缩放 / 平移 |
| 点小女孩 | 原地挥手蹦跳（坐秋千、坐长椅时也会打断） |
| 点小猫 / 小兔子 | 小猫蹦跳摇尾巴、兔子原地欢跳 |
| 点房子 | 进入室内场景 |
| 底部面板 | 昼夜切换、画质、环境音开/关、自动旋转、城市、拍照 |

**室内（点击房子进入）**

| 操作 | 效果 |
| --- | --- |
| WASD / 方向键 | 在房间里走动（卧室 / 起居室 / 厨房） |
| 按住拖拽 | 环视四周 |
| ESC / 「回到院子」按钮 / 点屋内木门 | 回到院子 |

屋内的窗户与房子外墙的门窗一一对应，透过窗户能直接看到院子里真实的草坪、篱笆与绿树。小女孩进屋休息时，会自己走去书桌前、坐床沿、看书架、在厨房台前忙活。

## 特色细节

- **真实时区与天气**：选择城市后按当地时刻自动昼夜切换，并调用 Open-Meteo 实时天气，雨雪雾各有视觉效果（时钟栏显示天气文字）
- **雨天小剧场**：下雨时小女孩自动撑起小红伞；雨停后白天会出现彩虹
- **夜晚限定**：窗灯、串灯、灯笼点亮，萤火虫与流星
- **院子生态**：锦鲤巡游、鸭子排队游泳、青蛙鼓腮、蝴蝶蜜蜂小鸟、向日葵追日、炊烟、气球与悬浮小岛
- **女孩的日常**：随机散步、池塘边看鱼、坐长椅、荡秋千（和小熊并排）、回房休息，五种状态自动切换
- **可选环境音**：面板「环境音 开/关」，默认静音；Web Audio 程序化软风 / 雨声 / 夜虫（无外部音频文件）

## 调试彩蛋

URL 加参数可强制天气，方便演示：

- `?wx=clear|cloudy|rain|snow|fog` 固定某种天气
- `?wx=cycle` 每 18 秒轮播五种天气（雨停时还能看到彩虹）
- `?t=day|night` 固定白天 / 夜晚（直接到位，不走过渡）；再加 `&style=anime` 就是动画雨夜的样子

控制台调试钩子：`__yard()` 查看状态、`__yardStep(n)` 手动推帧、`__yardGoto('swing')` 等触发指定活动。

## 人物模型

小女孩用的是 pixiv 官方开源的 VRoid 样例模型（`assets/girl.vrm`，即 three-vrm 仓库里的
`VRM1_Constraint_Twist_Sample.vrm`）。许可证为 [VRM Public License 1.0](https://vrm.dev/licenses/1.0/)：
允许修改、再分发和商用，无需署名。长棕发、白 T 恤、黑短裤，和参考视频里的女孩同款。

- 用 [@pixiv/three-vrm](https://github.com/pixiv/three-vrm) 加载，带真实人形骨骼：散步、坐长椅、荡秋千、进屋这些动作逐帧驱动髋 / 膝 / 脚 / 肩 / 肘 / 手指 / 脖子 / 头
- 头发和衣摆用模型自带的弹簧骨骼（spring bone）物理，走路、转身、荡秋千时会自然甩动；人物瞬移或进出屋时会重置物理，头发不会被甩飞
- 会自己眨眼，被点到时笑；眼睛会跟着镜头
- 雨天撑透明塑料伞（八根伞骨、白色滚边、伞面挂着水珠）
- 模型加载失败（离线等）时，退回到程序生成的人物

### 换成自己的角色

点面板上的「👤 换角色」选一个 `.vrm` 文件，或者直接把 `.vrm` 拖进页面，女孩就会换成这个模型。动作、头发物理、撑伞都照常，VRM 0.x 和 1.0 都支持。

- 换上的模型只存在你这台电脑的浏览器里（IndexedDB），下次打开自动加载，不会上传到任何地方
- 点「↺ 默认角色」可以换回来
- 也可以在本地运行时把模型放成 `assets/character.vrm`（已加入 `.gitignore`，不会被提交），或用网址参数 `?vrm=模型路径`

很多 BOOTH 上的免费 VRM 禁止再分发，所以**不要把这类模型提交进这个公开仓库**；用上面的方式在本地加载就好。换模型时页面会读出模型自带的许可信息，标了禁止再分发的会提示。

## 画面风格

默认是原版的暖色微缩风：奶油色天空、柔和的四阶卡通明暗、柔边阴影。

另有一套可选的**日系动画雨夜风**，网址加 `?style=anime` 打开（例如 `?style=anime&wx=rain&t=night`）。
效果是两阶赛璐璐明暗、墨线描边、夜晚整体沉进深靛蓝、灯和窗发光晕开；
下雨时地面积水能倒映出房子和灯光，水洼里有雨滴涟漪。

动画风的实现是先把场景画进 HDR 离屏缓冲，再统一做后期：

- **描线**：在深度缓冲的 1/z 上做拉普拉斯（平面恒为 0），再按采样跨度的视角归一化，
  轮廓和折过约 30° 以上的棱都会上线，大草坪、圆滑曲面不会出假线
- **积水 / 池塘倒影**：只对朝上的地面做屏幕空间反射，水洼分布用世界坐标噪声，雨天叠加程序化涟漪
- **泛光**：只让超亮像素（灯笼、窗、月亮）发光，夜晚和雨天更强
- **调色**：ACES 色调映射后略提饱和、暗部偏冷蓝；夜里按亮度把非灯光区域染成靛蓝

动画风需要 WebGL2，WebGL1 设备会退回默认画风的单遍渲染。「画质 低」会关掉 MSAA、泛光降到半分辨率、反射步数减半。

## 技术

Three.js r160 + three-vrm 3.5.5（jsDelivr CDN import map；需联网）+ 原生 WebGL 渲染，无构建；除人物 VRM 模型外，场景模型与可选环境音均为程序化生成，无其他外部贴图或音频素材。天气数据来自 [Open-Meteo](https://open-meteo.com/)（免费、无需密钥）。
